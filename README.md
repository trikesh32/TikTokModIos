# TikTokModIos

Мод TikTok для iOS с выбором региона и установкой через **AltStore Classic**.
Независимый проект, не связанный с TikTok / ByteDance.

## Установка через AltStore Classic

**1.1.0 — тестовая сборка.** Подготовка подписи Classic проверена тестами,
но установка и вход через сам AltStore ещё требуют подтверждения на iPhone.
Предыдущая 1.0.2 была проверена с отдельным локальным установщиком.

1. Установите AltStore Classic и настройте AltServer своим обычным способом.
2. В Sources добавьте этот URL:

   ```text
   https://raw.githubusercontent.com/trikesh32/TikTokModIos/main/altstore/source.json
   ```

3. Найдите **TikTok Mod** и установите тестовую версию.
4. Откройте **Профиль → ☰ → Настройки и конфиденциальность → Настройки мода**.
   Пункт расположен в секции аккаунта. После выбора страны полностью перезапустите TikTok.

[Релизы и IPA](https://github.com/trikesh32/TikTokModIos/releases) ·
[Сообщить о проблеме](https://github.com/trikesh32/TikTokModIos/issues)

Classic сам переподписывает IPA. В дистрибутиве нет сертификата автора,
профиля устройства или сохранённой сессии. Смена установщика/Apple Team может
потребовать повторного входа: Keychain мода изолирован. Удалять рабочую установку
для проверки не требуется. Приложение использует исходный Bundle ID до подписи,
поэтому может обновить уже установленный через Classic TikTok с тем же ID.
Источник не предназначен для AltStore PAL.

## Возможности

- Выбор CA, FR, DE, GB, US или KZ; включение и отключение подмены.
- Пункт в штатных настройках, без плавающей кнопки.
- Подмена региональных параметров и PNS-запросов; язык интерфейса сохраняется.
- Диагностика мода, которую можно скопировать по нажатию.
- Отдельный модуль для повторной упаковки при обновлении TikTok.

На исследованной версии удалось получить свежую ленту и открыть ранее
недоступные ролики из переписки без VPN. Это результат конкретного теста,
а не гарантия для всех аккаунтов, стран и версий. Просмотр лайков после
финального PNS-исправления отдельно не подтверждён.

## Совместимость

| Компонент | Состояние |
| --- | --- |
| TikTok | 47.6.0, исходный build 476038 |
| iOS / архитектура | минимум iOS 15, ARM64; все версии iOS не тестировались |
| Локальная подпись 1.0.2 | проверена на одном iPhone |
| AltStore Classic 1.1.0 | beta, требуется проверка на устройстве |
| Новые TikTok | статическая проверка 39 выбранных методов, затем ручной тест |

Расширения приложения исключены: виджеты, share extension и прочие интеграции
из исходного IPA не входят в сборку. Реклама не удаляется. Сетевые функции самого
TikTok сохраняются; мод не добавляет собственный сервер сбора диагностики.

## Сборка и обновления

Нужен Mac, Python 3.11+, command-line tools и iPhoneOS SDK. Сам SDK не включён.
Можно указать SDK из установленного Xcode; исследованная сборка использовала
iPhoneOS16.5 SDK из [theos/sdks](https://github.com/theos/sdks).

```bash
git clone https://github.com/trikesh32/TikTokModIos.git
cd TikTokModIos
IOS_SDK_PATH=/absolute/path/iPhoneOS.sdk ./tiktok-mod.command build
```

После сборки мод можно многократно встраивать в **свой расшифрованный IPA**:

```bash
./tiktok-mod.command inspect /path/TikTok.decrypted.ipa
./tiktok-mod.command pack /path/TikTok.decrypted.ipa \
  --altstore --distribution-build 476038.1100 \
  --output /path/TikTokModIos.ipa
```

Для неизвестного клиента потребуется `--allow-untested`. Флаг не отключает
проверки ABI, шифрования, архитектуры, подписи или целостности архива.
Получение и расшифровка IPA не входят в этот проект.

В релизах есть отдельный `tweak-kit`: для упаковки с ним не нужен SDK.
Инструкция генерации источника и обновлений: [UPDATE.txt](region-mod/UPDATE.txt).
Каждый релиз мода получает уникальный distribution build; номер версии TikTok
сохраняется. В карточке AltStore отдельно показываются версия клиента и мода.

## Проверки

```bash
python3 -m unittest discover -s region-mod/tests -p 'test_*.py'
IOS_SDK_PATH=/path/iPhoneOS.sdk bash region-mod/scripts/build-compatibility.sh --region-aggressive
```

Тесты проверяют ABI, сохранение callback, границы подмен, обновление нативного
меню, профили стран, обработку подписи Classic, упаковку и генерацию источника.
Наличие метода с прежней сигнатурой не доказывает прежнее поведение сервера.

При сообщении об ошибке укажите версию TikTok, мода, iOS, способ установки и
точный сценарий. Пароли, коды входа, токены и профили подписи не присылайте.
